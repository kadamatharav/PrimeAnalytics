# Amazon Prime TV Shows and Movies – EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on Amazon Prime TV shows and movies. The analysis explores content types, genres, release years, ratings, runtime, IMDb scores, actors, directors, and production countries.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Analysis Performed

* Movies vs TV Shows
* Top 10 Genres
* Titles by Release Year
* Ratings Analysis
* Runtime Analysis
* IMDb Score Analysis
* IMDb Score vs IMDb Votes
* Director and Actor Analysis
* Content Type vs IMDb Score
* Top-Rated Movies and TV Shows
* Country Analysis

## Conclusion

The project uses data analysis and visualization techniques to identify useful patterns and trends in the Amazon Prime content catalog.
